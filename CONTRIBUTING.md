# Contributing to Dashloom

Thank you for helping improve Dashloom.

1. Open an issue for significant features or data-model changes.
2. Keep product, connector, metric, and sync data scoped to a workspace.
3. Never add personal domains, provider IDs, credentials, or real customer data.
4. Add tests for authorization, retries, failure handling, and migration behavior when changing server functionality.
5. Run `npm run typecheck`, `npm run lint`, and `npm run build` before opening a pull request.

Connector contributions must document required permissions and must not request broader access than the implementation needs.
