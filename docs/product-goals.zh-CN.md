# 产品经营目标

产品目标让运营者先定义“成功是什么”，再让 Agent 提供建议。Dashloom 会用已经保存的指标数据计算每个目标的进度，并把计算结果冻结到符合条件的 Agent 分析中。

## 创建目标

打开 **Products → Operating targets**，选择产品并填写：

- 标准化指标，例如 `revenue`、`mrr`、`sessions`、`clicks` 或 `error_rate`；
- 可选数据源：只希望使用某一个连接器的数据时填写；
- 可选 ISO 货币：避免把不同货币的收入合并；
- 增长目标使用 `at least`，成本、错误率等上限使用 `at most`；
- 滚动每日、每周、每月或每季度周期；
- 目标值。

只有工作空间 Owner 和 Admin 可以创建、暂停、启用或删除共享目标，所有修改都会进入审计日志。

## 进度如何计算

滚动周期分别包含截至数据日期的 1、7、30 或 90 个自然日。Dashloom 使用指标自身的确定性聚合规则：

- 收入、会话、请求量等累计指标求和；
- MRR、付费客户等快照指标取最新值；
- CTR、流失率、错误率等比例指标取平均值。

目标状态分为 `achieved`、`at risk`、`off track` 和 `no data`，状态在调用模型之前已经确定。

## Agent 证据

当目标指标符合所选专项 Agent 的数据范围时，启用的目标会成为 `goal:<goal-id>` 形式的证据。目标名称一律按不可信数据处理。Agent 可以引用目标证据分析达成情况，但不能自行修改目标、虚构进度或把目标当成因果证明。

每次分析都会冻结当时的目标、周期、实际值、进度与状态，因此历史分析仍可复核。工作空间导出包含目标定义；便携导入会把目标重新映射到匹配产品，同时剥离历史私密分析。
