# 自定义计算指标

Dashloom 可以在 Agent 分析之前，先把标准化数据源指标转换为确定性的业务指标。适合计算转化率、每客户收入、扣除退款后的收入、百分比或单位换算。

## 创建公式

进入 **数据源 → 计算指标**。工作空间 Owner 和 Admin 可以配置：

- 稳定的输出指标名，例如 `revenue_per_paid_user`；
- 左侧数据源和指标；
- 加、减、乘、除运算；
- 另一个数据源指标，或一个数值常量；
- 可选缩放系数，例如用 `100` 把比率表示成百分比。

每个工作空间最多可保存 50 个定义，以保证同步任务的执行边界可控。

例如，`stripe.revenue ÷ stripe.paid_users × 1` 会得到每付费用户收入；`ga4.conversions ÷ ga4.sessions × 100` 会得到百分比转化率。

## 对齐与安全规则

Dashloom 会先按照指标自身的聚合语义处理两个操作数，再按工作空间、产品、自然日和兼容币种进行对齐。系统会跳过不唯一匹配、除零、跨币种运算，以及两个金额指标相乘等缺少业务含义的结果。公式不能依赖另一个计算指标，因此不会产生依赖循环，也不会执行任何用户代码。

结果会以 `calculated` 数据源写入标准化的 `metric_points`，并在维度中保留公式 ID。因此看板、告警、报告和 Agent 证据可以沿用与真实数据源相同的受控数据路径。

## 刷新机制

Cloudflare、Google、D1、Stripe 或 Lemon Squeezy 同步完成后，系统会重建最近 30 天的计算窗口。公式刷新失败会单独返回，不会把已经成功的数据源同步错误地标记为需要重试。如果通过其他方式修改了源数据，可以点击 **重新计算**。

删除公式时会同步删除它生成的计算点。工作空间导出包含公式定义和计算结果；便携导入会有意忽略公式定义，因为目标工作空间的数据源命名和单位必须重新审核。
