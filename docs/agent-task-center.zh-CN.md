# 查看和重试 Agent 任务

Agent 一直转圈、分析失败，或者你想知道任务发生了什么时，打开 **Agent → Tasks**。这里显示当前工作空间最近 50 次任务。

## 列表里能看到什么

- 任务是排队中、运行中、成功、失败还是已取消；
- 是用户手动发起，还是由报告、告警等功能触发；
- 分析了全部产品还是某一个产品；
- 运行耗时、输入和输出 Token；
- 可以安全显示的错误类别；
- 当前部署是否连接了可用的 BYOK 模型。

Community 通过你自己的 OpenAI 兼容 Provider 运行 Agent，不使用 Dashloom 托管额度。

## 什么时候可以直接重试

失败任务旁边出现 **Retry** 时，可以直接重试。系统会使用原来的问题和产品范围，但会重新检查你的权限、最新数据和模型连接。

以下情况不会提供自动重试：

- 原任务来自定时计划；
- 对话已经归档；
- 原来选择的产品已经删除；
- 任务太旧，或保存的数据不完整。

遇到这些情况，页面会说明原因。回到原功能重新发起即可，不要根据旧任务猜测参数。

## 排查顺序

1. 先看错误类别和产品范围。
2. 打开任务关联的数据快照，确认数据日期和引用是否完整。
3. 检查数据源和 BYOK 模型连接。
4. 条件恢复后再重试一次。

任务中心不会保存模型厂商返回的原始报错，也不会显示 API Key。需要排查问题时，请提供任务时间、稳定错误码和页面截图，不要发送密钥。
