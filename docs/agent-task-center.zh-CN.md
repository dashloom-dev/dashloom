# Agent 任务中心

`/dashboard/tasks` 是工作空间级的 Agent 执行台账，展示最近 50 次分析任务的排队、执行、成功、失败和取消状态，以及触发方式、产品范围、耗时、输入与输出 Token 和稳定错误码。模型容量只反映当前部署是否连接了可用的 BYOK Provider。

只有满足以下条件的失败或取消会话任务才可自动重试：系统能从冻结证据中恢复完整原始问题、会话仍处于 Active 状态、锁定的产品仍然存在。重试复用现有分析接口，因此会重新校验成员权限、租户范围、证据新鲜度、模型可用性和当前额度。计划任务、旧任务、已归档会话、已删除产品或证据损坏的任务不会被系统猜测性重建；任务中心会说明需要手动重新发起的原因。

列表不会持久化或展示模型与 Provider 的原始错误，只展示稳定错误分类，并提供冻结证据审计页入口。
