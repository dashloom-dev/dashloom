# 接入 Vercel 部署健康

Dashloom 会把近期 Vercel 部署结果关联到产品，使 Operations Agent 和 Portfolio Agent 能够把交付活动与流量、收入、运行证据放在一起比较。系统只读取项目元数据和部署摘要，不读取环境变量、源码、构建日志或部署文件内容。

## 创建访问权限

1. 打开 **Vercel 账号设置 → Tokens**，创建带有过期时间的 Access Token。
2. 把 Token 限定到拥有该项目的个人账号或 Team。
3. 如果项目属于 Team，从 Team 的通用设置复制 Team ID。
4. 复制项目 ID 或准确的项目名称。

访问 Team 资源时，Vercel 要求请求携带 Team ID。即使 Token 本身有效，Team ID 缺失或不匹配通常也会返回 403。

## 连接与同步

进入 **Dashboard → 数据源 → Vercel 部署健康**，选择 Dashloom 产品，填写项目、可选 Team ID 和 Access Token，然后连接。Token 会先通过只读项目接口验证，再进行加密保存。

手动或定时同步会导入最近 30 天的数据：

- 每日部署总数、成功数、失败数、取消数和生产部署数；
- 同时具有创建与 Ready 时间戳的部署，其每日平均就绪耗时；
- 最近一次已完成部署是否成功；
- 距离最近部署的天数。

每个项目每次同步最多读取 300 条部署记录，达到上限时响应会明确标记为截断。Dashloom 不会把部署耗时描述成请求延迟或终端用户性能。

## 故障排查

- **403：** 检查 Token Scope 和 Team ID。
- **404：** 检查项目 ID/名称及账号范围。
- **429：** 等待 Vercel 返回的速率限制重置时间。
- **没有耗时指标：** Vercel 的部署摘要没有提供有效 Ready 时间；其他结果数量仍可同步。

需要轮换 Token 时，重新连接同一个 Vercel 账号即可。
