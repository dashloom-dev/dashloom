# 首次价值路径

Dashloom 在工作空间首页把激活过程变成可见且有证据支撑的路径。它不使用“已完成引导”标记、预置产品或演示指标；每一个完成状态都直接根据当前工作空间数据库计算。

## 新工作空间向导

首次成功分析之前，首页只展示获得第一个有效答案所必需的三个步骤：

1. **创建产品。** 添加 Dashloom 需要理解的真实产品。
2. **连接真实数据。** 仅保存连接并不算完成；最近指标证据写入后才完成。如果数据源已连接但尚未写入数据，向导会提示执行首次同步。
3. **查看首次分析。** 已有证据但模型尚不可用时，向导先进入模型配置；模型就绪后直接进入 Agent，生成带证据链接的分析。

首次分析成功后，三步向导会切换为下方的完整运营闭环里程碑。

## 七个里程碑

1. **添加真实产品。** 至少存在一个启用状态的产品。
2. **映射或导入数据源。** 已启用的资源映射属于连接正常的 Provider 账号，或者鉴权数据接入已经写入近期证据。
3. **采集近期证据。** 最近 14 天内至少保存了一个真实指标点。
4. **启用 AI 模型。** 已连接 BYOK Provider，或者工作空间拥有托管额度且部署方已经配置托管模型。
5. **运行 Agent。** 至少成功完成一次带证据链接的分析。
6. **规划 Agent 行动。** 一条建议已经进入“已规划”“进行中”或“已完成”；只生成或驳回建议不计入完成。
7. **建立定期循环。** 至少启用一个每日、每周或每月报告计划。

页面始终把最早缺失的里程碑作为下一步。如果用户以不同顺序完成工作，已经有真实证据的后续步骤仍会如实显示为完成。

## 为什么采用严格定义

这条路径衡量的是产品经营闭环，而不是账号设置动作。保存凭证不等于获得数据，LLM 回复不等于事实证据，生成建议也不等于执行。社区部署不会把虚构数据混入真实工作空间。
