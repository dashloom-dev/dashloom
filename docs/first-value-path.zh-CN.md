# 快速开始：从空工作空间到第一份分析

第一次使用 Dashloom，只需要完成三件事：创建产品、接入一份真实数据、让 Agent 回答一个具体问题。顺利的话，整个过程只需要几分钟。

## 开始前准备

先选一个最容易接入的数据源。常见选择是 Cloudflare、Google Analytics、Stripe、GitHub 或 Vercel。你需要对应平台的只读 Token 或 OAuth 授权。

Dashloom 不会自动放入演示数据，所以新工作空间一开始是空的。这是正常现象。

## 第一步：创建产品

1. 登录后打开 **Products**。
2. 点击创建产品，填写真实产品名称和域名。
3. 保存后，产品卡片会显示 **not connected**，提示你接入数据。

一个产品代表你要持续观察的一项业务。不要把不同业务、不同客户或不同币种的数据塞进同一个产品里。

## 第二步：接入并同步数据

1. 点击产品卡片上的 **Fix data coverage**，或打开 **Data sources**。
2. 选择你实际使用的平台，并按对应接入指南创建最小权限凭证。
3. 把平台账号或资源映射到刚才创建的产品。
4. 点击 **Sync**，等待同步完成。
5. 回到 **Products**，确认产品卡片出现数据点数量和最近数据日期。

“账号已连接”不等于“数据已导入”。只有产品卡片出现真实数据日期，才算完成这一步。

## 第三步：运行第一次分析

1. 打开 **Agent**。
2. 选择与你的数据相符的分析师，例如 Revenue、SEO 或 Operations。
3. 选择刚才的产品。
4. 问一个能直接做决定的问题，例如：“最近 7 天最值得先处理的问题是什么？”
5. 打开回答中的数据引用，确认日期、指标和产品都正确。

如果某个 Agent 仍然不可选，页面会告诉你缺少哪类数据。先回到数据源页面完成同步，不要为了让按钮可用而接入无关指标。

## 怎么确认已经成功

完成后，你应该能看到：

- 产品卡片状态为 **live**，并显示最近数据日期；
- Agent 页面显示可用于分析的数据点数量；
- 至少有一次成功分析，结论可以点回对应数据；
- **Agent actions** 中出现可跟进的建议。

## 接下来做什么

建议按这个顺序继续：

1. 在 **Automation** 为重要数据源设置自动同步；
2. 把一条 Agent 建议设为 planned，并指定负责人；
3. 创建每周报告，让系统固定复盘同一时间窗口；
4. 再接入第二类数据，例如把流量与收入、发布与错误率放在一起看。

首页后续会显示七项进度：产品、数据映射、近期数据、AI 模型、Agent 分析、行动计划和定期报告。它们都根据真实数据和实际操作计算，不是可以随手勾选的教程清单。
