# Executive Brief（高管简报）

Executive Brief 把 Dashloom 的多个专项 Agent 组合成一次有证据链的经营复盘。Owner 或 Admin 可以选择 2—5 个已具备数据条件的专项 Agent，用一个决策问题同时发起分析，最终得到按优先级排列的简报，并能回到每个专项分析的原始证据。

## 使用方式

1. 打开 **Agent → Executive Brief**。
2. 选择全部产品或一个真实产品，再选择至少两个在该范围内显示为可用的专项 Agent。
3. 输入一个边界明确的经营问题并运行。
4. 查看优先事项；点击任意结论即可核对该专项 Agent 冻结的证据和引用。

Portfolio、Revenue、SEO Growth、Operations 与 Client Reporting 分别使用独立的数据适配规则。服务端会把同一个不可变范围应用到全部所选 Agent；单产品简报会排除其他产品的指标、目标、竞品、Mission 与行动。每个 Agent 单独冻结证据、调用模型并校验引用，Dashloom 再用确定性规则排序并保留原始分析运行链接。

## AI 额度与失败隔离

- BYOK 工作空间单次最多运行 5 个专项 Agent。
- 社区版需要连接 BYOK Provider，并在当前部署内最多运行五个所选 Agent。
- 各 Agent 独立运行。某个模型调用失败时，已经成功的结果仍会保存，简报状态显示为 `partial`。
- 因为一次操作可能消耗多次模型调用，只有 Owner 与 Admin 可以创建简报；普通成员可以查看已保存结果。

## 定时生成与渠道推送

打开 **Reports → Schedule recurring intelligence**，选择 **Executive Brief**、产品范围和 2—5 个已就绪的专项 Agent。计划支持日报、周报、月报、IANA 时区、可复用的决策问题，以及一个可选的加密推送渠道。

每次发生时，每个 Agent 都会按照对应周期独立冻结证据。“计划 ID + 发生时间”组成稳定幂等键，因此渠道重试不会再次生成简报或重复消耗模型额度。生成的报告会反向链接到 Executive Brief，报告正文也会保留每个专项运行 ID 与引用的证据 ID。

## 数据与审计边界

问题、确定性摘要、稳定失败代码和专项运行 ID 按工作空间隔离，并携带明确的全产品或单产品范围。删除产品不会把历史单产品简报变成全产品简报。每条优先事项都能回到原始冻结证据。Executive Brief 历史遵循工作空间的分析数据保留策略，并会进入 Owner/Admin 的完整工作空间导出；模型凭证永远不会被导出。
