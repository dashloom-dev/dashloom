# 看懂产品的数据状态

在 **Products** 页面，每张产品卡都会告诉你：数据有没有接上、最近一次数据是什么时候、哪些 Agent 现在可以使用。排查“为什么 Agent 不可用”时，先看这里。

## 卡片上的四种状态

- **live：** 最近三个 UTC 自然日内有新数据，可以正常分析；
- **stale：** 以前导入过数据，但最近三天没有更新；
- **awaiting sync：** 数据源已经映射到产品，但还没有成功导入数据；
- **not connected：** 还没有为产品接入任何数据。

数据源旁边出现 **attention**，表示账号没有配完、已停用或同步需要修复。

## 状态不正常时怎么处理

1. 点击产品卡片上的 **Fix data coverage**。
2. 检查数据源账号是否启用、凭证是否有效、资源是否映射到正确产品。
3. 手动执行一次同步。
4. 回到 **Products**，查看数据点数量和最近数据日期是否更新。
5. 再打开 Agent，确认对应分析师已经可选。

## 为什么“已连接”还不算完成

保存 Token 或完成 OAuth，只说明 Dashloom 获得了读取权限。只有同步成功并写入指标后，系统才有东西可分析。因此页面以实际保存的数据日期判断状态，不以“连接按钮点过了”判断。

每张产品卡还会显示数据源数量、指标序列数量、数据点数量和可用 Agent。手动导入或通过 API 写入的数据也会计入，即使它没有对应的连接器账号。

## Agent 为什么只亮一部分

每类 Agent 只使用与职责匹配的数据：Revenue 需要收入类指标，SEO 需要搜索数据，Operations 需要运行或部署数据。某个产品有很多无关数据，不会让所有 Agent 自动可用。

所有查询都限定在当前工作空间和当前产品。产品状态页只读取聚合指标，不会显示连接器密钥，也不会自动添加演示产品或虚构数据。
