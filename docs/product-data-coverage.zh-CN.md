# 产品真实数据覆盖

**Products** 页面是判断 Dashloom 产品是否真正接入数据的事实入口。创建产品不代表已经映射 Provider，配置账号也不代表同步已经成功写入证据。

每张产品卡会合并工作空间隔离的连接器映射和已保存的指标聚合，显示数据源数量、指标序列数量、已保存数据点、最新证据日期，以及在当前 14 天交互窗口内拥有匹配证据的五类专用 Agent。只有明确关联到该产品、且指标满足同一专家策略的竞品数据才会计入准备度。

## 覆盖状态

- **live：** 至少一个来源在最近三个 UTC 自然日内写入了证据；
- **stale：** 存在历史证据，但没有来源在三天内保持新鲜；
- **awaiting sync：** 已存在启用且账号正常的映射，但尚未写入指标；
- **not connected：** 产品既没有映射，也没有导入指标证据。

单个数据源还可能显示 **attention**，表示映射存在，但账号仍在等待配置、已经禁用或需要修复。通过标准化 API 或手动导入的数据即使没有连接器映射也会显示，数据新鲜度始终取自真正保存的指标日期。

所有查询都带有当前工作空间边界。页面只读取聚合证据，不会暴露连接器凭证，也不会向用户工作空间加入示例产品或演示指标。

点击 **Fix data coverage** 可以进入数据源页面修复账号或映射、执行同步，然后回到 Products 核对真实证据日期。只有存在自身匹配证据时 Agent 才会启用；无关的高频指标不会让另一个专项 Agent 被误判为可用。
