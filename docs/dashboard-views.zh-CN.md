# 可复用数据看板

五类内置看板始终作为稳定的分析模板。工作空间成员可以在 **Settings → Dashboard templates** 中保存额外的决策视图，不会修改底层标准化数据。

保存的视图可以设置：

- 五类基础模板之一；
- 显示名称、标题和说明；
- 一到八个标准化指标名称；
- 全部产品或工作空间中的单个产品；
- 是否作为该基础模板的默认视图。

可以从设置页打开保存的视图。如果某个视图被设为默认，直接打开基础看板地址且不带 `view` 查询参数时也会自动使用它。系统始终同时校验视图 ID、当前工作空间和模板类型，其他工作空间的链接不能暴露配置或产品数据。

删除视图不会删除指标、产品、Agent 运行或报告。工作空间导出中会保留看板配置。
