# 保存一个常用看板

如果你经常查看同一组产品和指标，可以把它保存成看板视图。以后从设置页直接打开，不用每次重新筛选。

## 创建视图

1. 打开 **Settings → Dashboard templates**。
2. 选择一个基础看板模板。
3. 填写视图名称、页面标题和说明。
4. 选择 1–8 个指标。
5. 选择全部产品，或只绑定一个产品。
6. 需要时，把它设为该模板的默认视图。
7. 保存并打开，确认指标和产品范围正确。

Dashloom 提供五类内置模板。保存视图只是在现有数据上保存一组展示设置，不会复制或修改指标。

## 默认视图怎么工作

把某个视图设为默认后，直接打开对应基础看板时，Dashloom 会自动加载它。带有明确 `view` 参数的链接仍会打开链接指定的视图。

视图 ID、工作空间和模板类型会同时校验。把另一个工作空间的视图链接复制过来，不会看到对方的配置或产品数据。

## 修改或删除

需要换指标或范围时，可以编辑保存的视图。删除视图只会删掉这组展示设置，不会删除产品、指标、Agent 任务或报告。工作空间导出会包含看板配置。
