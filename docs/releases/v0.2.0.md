# Dashloom v0.2.0

## English

Dashloom v0.2.0 expands the project from a Cloudflare-only runtime into a portable, bilingual product intelligence workspace.

### Highlights

- Run on Cloudflare Workers with native D1, or deploy the Next.js runtime to Vercel and AWS Amplify.
- Use Cloudflare Remote D1 or Supabase PostgreSQL with the Node.js runtime.
- Keep the D1 and PostgreSQL schemas aligned across 38 application tables.
- Switch the dashboard between English and Simplified Chinese, with clearer tabs, account controls, loading states, and workspace settings.
- Focus the source catalog on business data: Google Analytics, Google Search Console, Bing Webmaster Tools, Cloudflare D1 business data, Stripe, Lemon Squeezy, Creem, Polar, Paddle, and custom ingestion.
- Add bilingual deployment, scheduling, backup, recovery, architecture, and compatibility documentation.

### Compatibility note

Existing infrastructure-operation routes and mappings remain available for compatibility, but Cloudflare platform operations, GitHub, Vercel, and Supabase operations are no longer presented as new business data sources in the dashboard.

### Validation

The release passed both TypeScript configurations, ESLint, 160 automated tests, Next.js Remote D1 and Supabase production builds, the Cloudflare Vinext build, extension validation, agent evaluations, and a connector Worker dry run.

## 中文

Dashloom v0.2.0 将项目从仅支持 Cloudflare 的运行方式，扩展为可移植、支持中英文的产品智能工作台。

### 主要更新

- 可继续使用 Cloudflare Workers 与原生 D1，也可将 Next.js 运行时部署到 Vercel 或 AWS Amplify。
- Node.js 运行时可选择 Cloudflare Remote D1 或 Supabase PostgreSQL。
- D1 与 PostgreSQL 的 38 张应用表保持结构一致。
- 仪表盘支持英文与简体中文切换，并新增更清晰的标签页、账户菜单、加载状态和工作区设置。
- 数据源目录聚焦业务数据：Google Analytics、Google Search Console、Bing Webmaster Tools、Cloudflare D1 业务数据、Stripe、Lemon Squeezy、Creem、Polar、Paddle 和自定义数据接入。
- 补充中英文部署、定时任务、备份恢复、架构和兼容性文档。

### 兼容性说明

已有的基础设施操作路由与映射仍会保留以兼容现有配置，但 Cloudflare 平台操作、GitHub、Vercel 和 Supabase 运维能力不再作为新的业务数据源展示在仪表盘中。

### 验证结果

本版本已通过两套 TypeScript 配置检查、ESLint、160 项自动化测试、Remote D1 与 Supabase 两种 Next.js 生产构建、Cloudflare Vinext 构建、扩展校验、Agent 评测和连接器 Worker dry run。
