# Dashloom Community v0.6.0

Dashloom Community v0.6.0 brings the latest reusable product and Agent improvements from Dashloom Cloud into the standalone open-source edition without introducing a runtime, database, deployment, or Git dependency on the private repository.

## Highlights

- Discover likely revenue, order, signup, and active-subscription fields from a read-only Cloudflare D1 schema, confirm the mapping, and generate bounded aggregate queries without writing SQL.
- Attach up to four validated PNG, JPEG, or WebP images to a BYOK Agent request. Raw image content is sent only to the configured model for that request; history retains hashes and evidence IDs, not the original files or filenames.
- Show live and persisted Agent execution states, plus a concise evidence-linked reasoning summary that explicitly is not private chain-of-thought.
- Exclude bounded Search Console query/page breakdown rows from aggregate dashboard loading so they cannot double count headline metrics.
- Remove duplicate navigation prefetch behavior and recover stalled client navigation with a full-page fallback.

No application schema migration is included in this release.

## 中文摘要

Dashloom Community v0.6.0 将 Dashloom Cloud 中可复用的产品与 Agent 优化同步到独立开源版本，同时不引入对私有仓库的运行时、数据库、部署或 Git 依赖。

- 只读识别 Cloudflare D1 中可能对应收入、订单、注册和活跃订阅的字段，确认后自动生成受限汇总查询。
- BYOK Agent 每次请求可附带最多四张通过类型、大小和文件签名校验的 PNG、JPEG 或 WebP 图片；历史记录只保留哈希与证据 ID。
- 展示实时并持久化的 Agent 执行轨迹，以及带证据引用的可读推理摘要；它不是私有思维链。
- 聚合看板会排除 Search Console 的关键词与页面明细，避免重复计算。
- 移除重复导航预取，并在客户端导航卡住时使用完整页面跳转恢复。

本版本不包含应用数据库 Schema Migration。
