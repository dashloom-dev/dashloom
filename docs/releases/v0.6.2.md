# Dashloom Community v0.6.2 — unreleased

This change synchronizes reusable updates from Cloud 0.6.4 (`aef6f10`) and 0.6.5 (`7c163af`) on top of Community v0.6.1. Pushing this branch does not publish a GitHub Release or deploy a site.

## Synced changes

- The overview shows real available metrics before setup guidance instead of fixed user, revenue, and request placeholders. It uses the latest matching data date, a 30-day window and the preceding 30-day comparison.
- The overview and data dashboard share metric selection, currency-aware rollups and formatting. Saved default metrics and product scope apply consistently; stock metrics use each product's latest observation and ratio metrics use averages.
- Active product count, latest data date and current-period point count are explicit. A link opens the matching 30-day dashboard.
- Data dashboard is the first Data navigation entry and its mobile shortcut.
- Community settings describe capacity as deployment-managed and distinguish the sync safety floor from commercial plan allowances. Enforcement limits are unchanged.

## Community adaptations and exclusions

- Exact search query/page breakdown metrics remain excluded from headline KPI queries; GA4 `page_views` remains eligible.
- Missing current-period currencies do not create zero-valued cards, and missing observations do not dilute ratio averages. Real zero values remain visible.
- Cloud's new Free-plan initialization, `DASHLOOM_EDITION=cloud`, billing UI and hosted AI credits are not imported. Both Community schemas already restrict plans to `community`; authentication and single-deployment locale behavior remain unchanged.
- No application schema, migration, dependency, credential or hosting configuration changes are required.

## Validation

- 238 unit and source-contract tests passed; lint passed.
- D1/default and Supabase TypeScript checks passed.
- Vinext/Cloudflare, Next.js and Supabase production builds passed.
- Community extension validation and all 6 Agent evaluation fixtures passed.
- Connector Worker type checks and deployment dry-run passed; nothing was deployed.

## 中文摘要

在 Community v0.6.1 基础上，同步 Cloud 0.6.4–0.6.5 中适用于独立开源部署的更新：

- 总览优先展示真实指标、30 天环比、最新数据日期与本期数据点数量；不再用固定指标和零值占位。
- 总览与数据大盘共用指标选择、币种隔离、汇总与格式化规则，并保持默认视图的产品范围一致。
- 数据大盘入口前置，移动端数据导航也直接进入大盘。
- 设置页明确自部署容量与系统安全下限，不再把内部护栏显示成订阅额度；实际限制不变。
- 补充缺失数据、真实零值、币种、存量及平均指标、权限过滤和导航回归测试。

不引入 Cloud Free 套餐、计费或托管 AI 依赖。本次无数据库迁移；仅同步并推送 Git，不执行站点部署或正式 Release 发布。
