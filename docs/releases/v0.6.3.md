# Dashloom Community v0.6.3

## Agent capability upgrade

- SEO Growth Agent now turns frozen Google Search Console query and page evidence into a deterministic opportunity shortlist.
- It identifies high-impression/low-CTR records, ranking positions 4–20 worth improving, and material click declines.
- Every opportunity preserves its original evidence references and remains isolated by product, source, and query/page dimension.
- Missing periods are not treated as zero, incomplete daily coverage is excluded, and results are bounded and disclose truncation.
- The Agent separates visibility, CTR, ranking, and click changes before suggesting a concrete experiment, success metric, and review period.
- It does not invent keyword difficulty, CPC, backlinks, domain authority, traffic forecasts, live SERP audits, or external tool calls.
- English and Chinese starter questions now lead directly into these evidence-backed SEO workflows.

No database migration is required.
