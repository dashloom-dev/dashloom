# Dashloom Community v0.6.1

Dashloom Community v0.6.1 continues the reusable product improvements from Dashloom Cloud 0.6.2–0.6.3 while preserving the standalone open-source deployment boundary.

## Highlights

- Replace the narrow saved-view summary with a unified data dashboard for each preset.
- Use one selectable 7, 30, or 90 day range across KPI cards, product trends, rankings, and comparison periods.
- Discover and prioritize metrics that actually exist in the active workspace instead of rendering missing configured metrics as zero.
- Surface latest data date, last collection time, source sync health, current-period point counts, and the active product scope.
- Keep saved Agent reports visible while clearly separating their frozen evidence snapshot from the dashboard's live filtered data.
- Add responsive layouts for dashboard controls, KPI cards, charts, and product rankings.

No application schema migration is included in this release.

## 中文摘要

Dashloom Community v0.6.1 继续同步 Dashloom Cloud 0.6.2–0.6.3 中可复用的产品优化，并保持开源版本可独立部署。

- 将原有的常用视图摘要升级为统一的数据大盘。
- KPI、趋势、产品排行和环比统一支持近 7、30、90 天时间范围。
- 自动发现并优先展示当前工作区真实存在的指标，不再用 0 填充缺失指标。
- 展示最新数据日期、最近写入时间、数据源同步状态、本期数据点数量和产品范围。
- 保留已保存的 Agent 报告，并明确区分冻结报告快照与大盘当前筛选数据。
- 完善大盘筛选器、指标卡、图表和产品排行的响应式布局。

本版本不包含应用数据库 Schema Migration。
