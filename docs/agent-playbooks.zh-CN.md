# Agent Playbook

Agent Playbook 用来告诉每一位 Dashloom 专项分析师：它正在服务哪类业务，以及应该如何从证据中确定优先级。进入 **Agent**，选择分析师，然后在对话工作台上方配置 Playbook。

## 可以配置什么

- **业务模式：**独立产品组合、SaaS、代理商、内部平台或私有自托管部署。
- **首要目标：**一句简短的经营结果，例如提升留存 MRR 或减少部署回归。
- **关注重点：**最多五类受限领域，包括收入、增长、留存、SEO、可靠性、交付和客户结果。
- **变化敏感度：**让分析师关注较小变化，或只报告更显著的移动。
- **表达风格与语言：**简洁、管理层摘要或详细分析；可使用英语、简体中文，或跟随问题语言。

只有工作空间 Owner 和 Admin 可以修改共享 Playbook；Member 可以使用已经保存的配置运行 Agent。

## 证据与安全边界

Playbook 只影响优先级和表达方式，不会赋予模型新的数据访问或操作权限。Dashloom 把目标文本视为不可信业务上下文；它不能覆盖系统提示、指标策略、引用校验、币种隔离、不完整数据披露或输出合约。

每次新分析都会把当时生效的 Playbook 冻结在证据快照中。因此，即使之后修改了业务目标，历史运行仍然可以审计。审计事件只记录配置类别和优先级，不会复制自由文本目标。

## 推荐的首次配置

1. 选择 **Portfolio Analyst**，并选取最接近自己的业务模式。
2. 用自然语言写下一个可以判断结果的目标。
3. 只选择两到三个真正重要的方向，不要默认全选。
4. 在了解自身数据的正常波动前，先使用标准敏感度。
5. 保存后，点击一个推荐决策问题或输入自己的问题。
6. 执行重要建议前，先打开冻结证据链接核对来源。

每日、每周和每月定时报告也会使用 Playbook，因为报告运行的是同一套证据约束 Agent。
